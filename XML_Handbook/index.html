Using the output

 
Each line is a modifier followed by the attributes to set, for example Config: dragScale="0" massScale="0.5". In the craft XML, the modifier is a child element of the part and the attributes go on it, like <Config dragScale="0" massScale="0.5" />. If the part already has that element, add or edit the attributes there. Otherwise add the element.

 
Compatible attributes only

 
Choose a part type and the Modifiers box lists the ones that part normally uses, plus a few that work on any part (Part, Config, InputController, InputBasedActivator, FlightProgram). The game lets you add any modifier to any part, so tick Show every modifier if you need another one.

 
Hidden / Tinker properties

 
Inside each modifier, use Hidden / Tinker to show only properties that have no in-game tooltip. These are usually the ones that aren’t in the normal part panel. The game’s Tinker panel has a Show Hidden Properties checkbox. This tool can’t tell exactly which panel shows which property, so treat the label as a hint and test in game.

 
Values

 
Vectors are comma-separated like 0,1.45,0. True/False capitalisation is selectable beside the output. Craft files saved by the game use lowercase.

 
Keep a backup of the craft before editing it.
