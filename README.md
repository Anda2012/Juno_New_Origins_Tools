# Juno: New Origins Tools
Browser utilities for Juno: New Origins, hosted with GitHub Pages.

Each tool lives in its own folder with an `index.html`:
- `Craft_to_Subassembly/` – convert a craft XML to a subassembly, excluding chosen parts

Add a tool: create a new folder with an `index.html`, then add a link to it in the root `index.html`.
