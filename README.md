# Juno: New Origins Tools

A collection of free browser-based utilities for Juno: New Origins.
Every tool runs entirely in your browser, so your craft files are never uploaded anywhere.

**Open the tools:** https://anda2012.github.io/Juno_New_Origins_Tools/

## Tools

| Tool | What it does |
| --- | --- |
| Craft → Subassembly | Converts a craft XML file into a subassembly and lets you choose which parts to leave out. |

## Adding a tool
1. Fork the repository
2. Create a new folder with an `index.html`.
3. Optionally add an `app.json` with a `title`, `description` and `icon`.
4. Commit it. The homepage lists new folders automatically.
