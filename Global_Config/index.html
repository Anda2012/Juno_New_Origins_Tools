Global Config

Set a config or part attribute on every part in a craft at once, like massScale or dragScale. Pick the attributes, choose which parts, and download the edited craft. Existing values are overwritten. Your file never leaves your browser.

1 · Craft file

Tap to choose a craft or subassembly .xml
or drop it here

2 · Choose attributes

These attributes work on every part. Tick one and enter a value. It is written to every part you select, replacing the value if the part already has that attribute.

3 · Which parts

Only these bodies (leave all off for every body)

4 · Preview and download

Your original file isn’t changed. Keep a backup anyway before loading the edited craft in the game.
