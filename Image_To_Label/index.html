Image to Label

Turn any image into text for a Label part, sized in centimetres, with editable colours. Runs in your browser; your image is never uploaded.

1 · Image

Tap to choose an image
PNG, JPG, GIF, WebP, SVG, BMP… or drop / paste one here

2 · Output size

More characters means finer detail but longer code. Labels have a character limit, so squares up to about 200 across are safest.

Calibrate the scale

At Part Scale 1, one character cell is assumed to be cm. If your label comes out the wrong size, paste the code, measure the label’s width at Part Scale 1, and enter it here.

3 · Colours

Make this colour transparent:

Adjust the picture first

The Label has 25 colour slots. The first 10 colours use slots 16 to 25; colours 11 to 25 use slots 1 to 15, so check those slots can be edited in your game. Clear, high-contrast pictures with few colours convert best. For photos, turn on merging.

4 · Preview

5 · Colour editing

The code stores each colour as a slot number (the Label part has 25 colour slots). Set the same colours in the same slot order in the game. Tap a colour swatch in the list to change that colour. Tap a slot’s number to select it, then move it earlier or later.

6 · Output code

Clipboard too small? Copy in parts

Paste the parts into the Label part one after another, in order.

How to use

  1. Paste the code into the Label part’s text box.
  2. Set the Label’s Font to Future Earth, Horizontal Anchor to Left, Vertical Anchor to Top and Gradient to Vertical.
  3. Set the Part Scale in the Tinker panel to the value shown under Output size.
  4. Set the 25 slot colours in the Label part to match section 5, in the same order. The code can’t carry the colours.

If the picture looks wrong after pasting, drag FontSize, Width and Height to the maximum, then shrink them back.

The conversion logic (colour reduction, transparency and Label code format) is from the Image to Label tool in Qiqi29/jno-tools (MIT licence, web version). This page re-implements it with a new interface and adds centimetre sizing and colour editing.
